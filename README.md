# 将棋トレーナー — 公開用一式

このリポジトリには、アプリのソース資料とライセンスをまとめています。APKと評価データ `nn.bin` はファイルサイズが大きいため、GitHub の Releases から配布します。インストールだけならAPKだけで問題ないです。

## 内容

- `shogi-trainer.apk` — アプリ名「将棋トレーナー」、アプリID `jp.shogi.trainer`。デバッグ署名版なので、直接インストール用です。GitHub の Releases からダウンロードしてください。
- `LICENSES/GPL-3.0.txt` — 同梱エンジンのライセンス本文。アプリの設定画面からも開けます。
- `SOURCE/` — Webアプリ、GPL対象エンジンのソース、Android連携コード。APKを配布するときは対応するソースもこのリポジトリから取得できます。

問題データは自動生成されたもので、2,487問を収録しています。


## ソースの構成

- `SOURCE/engine-src/` — AobaNNUE / YaneuraOu のビルド元コードとライセンス
- `SOURCE/app/web/` — APKに入っているWebアプリ一式
- `SOURCE/project/` — npm / Capacitorの設定
- `SOURCE/eval/nn.bin` — APKで使う評価データ。Gitには含めず、GitHub の Releases からダウンロードしてください。
- `SOURCE/android/` — APKに含まれるエンジン連携コードとビルド設定
- `SOURCE/tools/` — APK生成スクリプト

ライセンス詳細: [YaneuraOu](https://github.com/yaneurao/YaneuraOu)、[AobaNNUE](https://github.com/yssaya/AobaNNUE)。

# 簡単な使い方説明
右上の歯車ボタンを押すと、いくつかの設定項目が現れます。最初のスライダーは一日の新しく出題される問題の数を調整できます。
次のスライダーは一セットでやる問題数の調整です。
BGMも入れることができます。自前で用意したMP3等を再生できます。Youtubeには対応してません。
効果音は正直チープなので、ドパるためにも自前のBGMを利用することをお勧めます。

黒い今日の問題は、復習と新しい問題を一度にやるモードです。問題数が多くなると問題を思い出せなくなったりするので、あまりお勧めはしません。
その下のれんしゅうを何度でもボタンは設定した一セットの数だけ練習するモードです。

## 問題の復習、追加について
一セット終えると、復習画面になります。そこでは問題を選択して、AIの解析を見ることができます。また、その問題盤面は実際に触って操作可能です。
また、問題について、"その後の変化でためになる問題が出た","これは一手当てるだけではなくてn手一組で当てなきゃいけない"等の問題意識を感じた場合新たに問題セットを作ってそこで新たな問題を登録することができます。
**登録の際は基本的に振り返り画面から行います。**　一応ほかにもSFENとUSIから追加できますが、基本使わなくてもいいと思います。
追加できる問題の種類は4種類あります
- 盤上で指して解答：そのなのとおり回答手を指すことで回答します。
- 手順を指して解答：n手一組です。応手は登録した手を自動で指してくれます。（正しければ）また途中からの出題もあり得ます。
- 二択：そのままです。
- 詰将棋：局面を指定するだけです。変化も完全につぶすため、AIがある程度ランダムに指します（21手詰めが3手詰めになるみたいな大悪手は指さないはず）
ちなみに問題セットにつき問題の種類は一種類だけです。　詰将棋用の問題セットを作ったら詰将棋の問題しか入れれません。
また、問題は選ばれている問題セットの中からのみ出題されます。横断的な出題には対応してないです。
## 問題について
すでにある問題はfloodgateに現れた局面のうち、Aobannueで５０００万ノード読んだ際の最善手と、DLSuishoのpolicy(第一感のようなもので、アマ四段ぐらいらしい　https://yaneuraou.yaneu.com/2022/07/19/the-strength-of-the-shogi-ai-of-the-policy-network-only/)を指した際の評価値の差がある程度あるとき、最善手を正解、policyを不正解とした二択問題を生成するという仕組みですので、正解は絶対的な最善手ではない可能性があります。
